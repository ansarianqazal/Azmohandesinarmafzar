# بازی مار (Snake Game)

این پروژه برای درس آزمایشگاه مهندسی نرم‌افزار با زبان پایتون پیاده‌سازی شده است. بازی از نمونه‌های کلاسیک مار الهام گرفته و بازیکن باید با تغییر جهت حرکت مار، میوه‌های ظاهرشده در صفحه را جمع‌آوری کند و امتیاز بیشتری به دست بیاورد.

## امکانات بازی

- حرکت پیوسته مار پس از فشردن دکمه شروع
- ادامه حرکت در جهت قبلی تا زمانی که بازیکن جهت جدیدی انتخاب کند
- کنترل حرکت با کلیدهای جهت‌دار و همچنین کلیدهای W، A، S و D
- نمایش مار با ایموجی مربع سبز 🟩
- ظاهر شدن تصادفی یکی از هفت میوه در محل خالی صفحه
- افزایش طول مار پس از خوردن میوه
- اختصاص امتیاز متفاوت به هر میوه
- پایان بازی در صورت برخورد سر مار با دیواره یا بدنه خودش
- امکان شروع دوباره بازی پس از باخت

## پیش‌نیاز

برای اجرای پروژه به Python 3 و کتابخانه Pygame نیاز است.

## نصب و اجرا

ابتدا ترمینال را در پوشه پروژه باز کنید و دستور زیر را اجرا کنید:

```bash
pip install -r requirements.txt
```

سپس بازی را با دستور زیر اجرا کنید:

```bash
python main.py
```

## روش بازی

1. روی دکمه `START` کلیک کنید.
2. مار به صورت خودکار شروع به حرکت می‌کند.
3. با کلیدهای جهت‌دار، مسیر حرکت را تغییر دهید.
4. با خوردن هر میوه، امتیاز مربوط به آن به امتیاز کل اضافه می‌شود و طول مار افزایش پیدا می‌کند.
5. اگر سر مار به دیواره یا بدن خودش برخورد کند، بازی تمام می‌شود.
6. برای شروع یک دور جدید، روی دکمه `START AGAIN` کلیک کنید.

## ساختار فایل‌ها

- `main.py`: شامل منطق بازی، حرکت مار، تشخیص برخورد، تولید میوه و نمایش صفحه‌ها
- `requirements.txt`: فهرست کتابخانه‌های موردنیاز برای اجرای پروژه

## نکته

برای نمایش درست ایموجی‌ها، بهتر است فونت ایموجی سیستم‌عامل فعال باشد. ظاهر ایموجی‌ها ممکن است با توجه به سیستم‌عامل کمی متفاوت باشد.
