# بازی مار (Snake Game)

این پروژه برای درس آزمایشگاه مهندسی نرم‌افزار با زبان پایتون و کتابخانه Pygame پیاده‌سازی شده است. در این نسخه، مار با شکل گرافیکی طراحی شده و به‌جای میوه، حیوانات مختلف را شکار می‌کند.

## امکانات بازی

- شروع بازی با کلیک روی دکمه START
- حرکت خودکار مار در جهت انتخاب‌شده
- کنترل با کلیدهای جهت‌دار یا W، A، S و D
- طراحی بدن مار با قطعه‌های گرد، فلس، چشم و زبان
- ظاهر شدن تصادفی حیوانات در صفحه
- تعیین تصادفی امتیاز هر حیوان در زمان ظاهر شدن
- وجود مار ویژه با اندازه بزرگ‌تر و امتیاز بیشتر
- افزایش طول مار پس از خوردن حیوان
- پایان بازی در صورت برخورد با دیواره یا بدن خود مار
- امکان شروع دوباره با دکمه START AGAIN

## نصب و اجرا

ابتدا Python 3 را نصب کنید. سپس در ترمینال، داخل پوشه پروژه، دستور زیر را اجرا کنید:

```bash
pip install -r requirements.txt
```

برای اجرای بازی:

```bash
python main.py
```

## روش بازی

1. روی START کلیک کنید.
2. مار به‌صورت خودکار حرکت می‌کند.
3. با کلیدهای جهت‌دار یا W، A، S و D مسیر حرکت را عوض کنید.
4. حیوانات را بخورید تا امتیاز بگیرید و طول مار بیشتر شود.
5. مراقب دیواره‌ها و برخورد با بدن مار باشید.
6. پس از پایان بازی، برای شروع دوباره روی START AGAIN کلیک کنید.

## ساختار فایل‌ها

- `main.py`: کد اصلی و منطق بازی
- `requirements.txt`: کتابخانه موردنیاز برای اجرا

## نکته

نمایش درست ایموجی حیوانات به پشتیبانی فونت ایموجی سیستم‌عامل بستگی دارد. در ویندوز معمولاً فونت Segoe UI Emoji برای این کار استفاده می‌شود.
