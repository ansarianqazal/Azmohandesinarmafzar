# بازی مار در ترمینال (Terminal Snake Game)

این پروژه برای درس آزمایشگاه مهندسی نرم‌افزار با زبان پایتون نوشته شده است. بازی در خود ترمینال اجرا می‌شود و برای نمایش آن پنجره گرافیکی جداگانه باز نمی‌شود.

## امکانات بازی

- اجرای کامل بازی داخل ترمینال
- حرکت خودکار مار و کنترل لحظه‌ای بدون نیاز به فشردن Enter
- کنترل با کلیدهای جهت‌دار یا W، A، S و D
- زمین بازی با رنگ سبز و بافت ساده چمن
- نمایش سر و بدن مار با رنگ نارنجی و طلایی برای تفاوت با چمن
- ظاهر شدن تصادفی حیوانات و اختصاص امتیاز تصادفی به هرکدام
- وجود مار بزرگ به‌عنوان هدف ویژه با امتیاز بیشتر
- افزایش طول مار پس از خوردن حیوان
- پایان بازی در صورت برخورد با دیواره یا بدن خود مار
- امکان شروع دوباره بازی

## حیوانات و بازه امتیاز

امتیاز دقیق هر حیوان در هر بار ظاهر شدن، به‌صورت تصادفی از بازه مربوط به خودش انتخاب می‌شود.

| حیوان | نماد ترمینال | بازه امتیاز |
|---|:---:|---:|
| موش | M | ۵ تا ۱۵ |
| خرگوش | R | ۱۰ تا ۲۵ |
| قورباغه | F | ۸ تا ۲۰ |
| پرنده | B | ۱۲ تا ۳۰ |
| مرغ | C | ۱۵ تا ۳۵ |
| لاک‌پشت | T | ۲۰ تا ۴۰ |
| مارمولک | L | ۱۸ تا ۳۸ |
| مار بزرگ | S | ۶۰ تا ۱۰۰ |

## پیش‌نیازها

- Python 3
- ترمینال VS Code، Windows Terminal یا CMD جدید
- هیچ کتابخانه جانبی نیاز نیست؛ بازی فقط از کتابخانه‌های استاندارد پایتون استفاده می‌کند.

## روش اجرا در ویندوز

1. پوشه پروژه را در VS Code باز کنید.
2. از منوی Terminal گزینه New Terminal را انتخاب کنید.
3. با دستور `cd` وارد پوشه‌ای شوید که فایل `main.py` در آن قرار دارد.
4. دستور زیر را اجرا کنید:

```bash
python main.py
```

اگر دستور `python` کار نکرد، از این دستور استفاده کنید:

```bash
py main.py
```

## روش بازی

1. پس از اجرای برنامه، منوی بازی در ترمینال نمایش داده می‌شود.
2. برای شروع، کلید Enter را بزنید.
3. مار به‌صورت خودکار حرکت می‌کند.
4. برای تغییر مسیر، کلیدهای جهت‌دار یا W، A، S و D را فشار دهید؛ برای تغییر مسیر نیازی به Enter نیست.
5. با خوردن حیوانات امتیاز می‌گیرید و طول مار افزایش پیدا می‌کند.
6. با برخورد به دیواره یا بدن خود مار، بازی تمام می‌شود.
7. در صفحه پایان بازی، کلید R برای شروع دوباره و Q برای خروج است.
8. در منوی شروع نیز با Q می‌توانید از بازی خارج شوید.

## نمادهای داخل زمین

- `@` سر مار
- `o` بدن مار
- حروف M، R، F، B، C، T، L و S حیوانات هدف

## ساختار فایل‌ها

- `main.py`: کد اصلی و منطق بازی
- `requirements.txt`: توضیح وابستگی‌های پروژه (نیازی به نصب کتابخانه اضافی نیست)
